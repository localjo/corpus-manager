# Corpus Manager

Corpus Manager is a lightweight VPS-ready implementation of a personal "LLM wiki" workflow inspired by Andrej Karpathy's second brain idea:  
  
[LLM Wiki: ingest once, query many](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f).

It lets you:

- capture notes into a Markdown vault,
- compile raw sources into a cross-linked wiki,
- query your own corpus from Claude.ai,
- sync the same vault to Obsidian on Mac and iPhone using Syncthing.

> NOTE: This repo and README were mostly generated by Claude itself and haven't been carefully human-reviewed. While it does work as a proof of concept, please don't rely on it for anything mission-critical. I'm running it for my own wiki on a DigitalOcean Basic Droplet with 1 vCPU, 2 GB RAM, 50 GB SSD, and 2 TB transfer (about $15/month with backups).

## Architecture

- **One remote MCP endpoint** exposed to Claude.ai.
- **Corpus Manager MCP server** handles orchestration (`ingest`, `query`, `lint`, etc.).
- **markdown-vault-mcp** runs alongside it for vault search/read primitives.
- **Syncthing** keeps your vault sync with your local Obsidian vaults.

## Requirements

- Ubuntu 24.04 VPS (or similar Linux host)
- Docker Engine + Docker Compose plugin
- Domain name for TLS (recommended for Claude.ai remote MCP)
- Anthropic API key
- Markdown vault structure:
  - `raw/`
  - `wiki/`
  - `manifest.json`
  - `CLAUDE.md`

## Project layout

- `src/corpus_manager_mcp/server.py` - MCP server implementation
- `docker-compose.yml` - deployment stack
- `.env.example` - required environment variables
- `skill/` - uploadable Claude Skill files
- `docs/md-mcp-integration.md` - transport decision notes

## Deploy on VPS

### 1) Clone project from GitHub and prepare directories

```bash
sudo mkdir -p /opt
cd /opt

# Use your repository URL from the GitHub page.
sudo git clone <your-github-repo-url> corpus-manager
cd /opt/corpus-manager

cp .env.example .env
sudo mkdir -p /srv/vault
sudo mkdir -p /opt/corpus-manager/syncthing-config
sudo chown -R 1000:1000 /srv/vault /opt/corpus-manager/syncthing-config
sudo chmod -R 775 /srv/vault /opt/corpus-manager/syncthing-config
```

### 2) Configure environment

Edit `.env`:

```env
VAULT_ROOT=/data/vault
CLAUDE_MD_PATH=/data/vault/CLAUDE.md
HOST_VAULT_PATH=/srv/vault
HOST_SYNCTHING_CONFIG_PATH=/opt/corpus-manager/syncthing-config

ANTHROPIC_API_KEY=replace-me
ANTHROPIC_MODEL=claude-sonnet-4-5
ANTHROPIC_QUERY_MODEL=claude-sonnet-4-5

HOST=0.0.0.0
PORT=8765
MCP_PATH=/mcp
MCP_BEARER_TOKEN=replace-me

MD_MCP_HTTP_URL=http://markdown-vault-mcp:8000
```

Generate a token:

```bash
openssl rand -hex 32
```

### 3) Start services

```bash
cd /opt/corpus-manager
docker compose up -d --build
docker compose ps
```

Expected services:

- `corpus-manager-mcp`
- `markdown-vault-mcp`
- `corpus-syncthing`

## TLS reverse proxy

Use a domain such as `mcp.example.com` pointing to your VPS public IP.

### Caddy (recommended)

Install and configure:

```bash
sudo apt update
sudo apt install -y caddy
sudo tee /etc/caddy/Caddyfile >/dev/null <<'EOF'
mcp.example.com {
  reverse_proxy 127.0.0.1:8765
}
EOF
sudo systemctl reload caddy
```

Your MCP URL is:

`https://mcp.example.com/mcp`

### Nginx alternative

```nginx
server {
    listen 80;
    server_name mcp.example.com;

    location / {
        proxy_pass http://127.0.0.1:8765;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Then issue TLS certs with certbot.

## Claude.ai setup

1. Add remote MCP server URL: `https://mcp.example.com/mcp`
2. Provide `MCP_BEARER_TOKEN` if prompted.
3. Upload Skill package from `skill/`.
4. Smoke-test with:
   - `stats`
   - `capture`
   - `query`

## Syncthing setup

### VPS side

- Open Syncthing UI at `http://<VPS-IP>:8384`
- Folder path inside Syncthing container should be:
  - `/var/syncthing/Vault`

### Mac side

- Add your local vault path
- Pair devices and accept shared folder.

### iPhone side (later)

- Use Möbius Sync (or equivalent iOS Syncthing client).
- Pair with VPS and map the same vault folder.
- Open synced folder in Obsidian iOS.

## Troubleshooting

- **MCP reachable but returns 406 with curl**  
Normal for raw curl requests to streamable MCP endpoints.
- **Syncthing cannot create cert.pem / permission denied**  
Ensure host folders are writable by UID/GID `1000:1000`:
`/srv/vault` and `/opt/corpus-manager/syncthing-config`.
- **Unexpected pending sources (metadata files)**  
Server ignores hidden/system/editor metadata (`.DS_Store`, `._`*, `.plist`, dotfiles).
- **Tool list in Claude.ai seems stale**  
Rebuild/restart container and reconnect MCP integration in Claude.ai.
